# handoff-17 (booth default)

**17-cube** fold library used by the iMessage / Linq bridge (`CUBOT_HANDOFF_DIR` default).

Shapes: heart, square, check, C, L, triangle, plus, zigzag.

Companion URDF / MuJoCo scene: `cubot_urdf/n17/`.
The shorter alternate catalog lives in `../handoff-11/` (not wired into iMessage by default).
