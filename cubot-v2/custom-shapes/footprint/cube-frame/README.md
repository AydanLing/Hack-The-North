# cube-frame

Formerly `lantern-4x4-2-wiresafe`. A hollow 4×4×3 cube cage (27 modules), folded in 15 moves.
Wire-safe route for wires leaving module 27.

Playable handoff export: `../../../handoff/shapes/136-cube-frame/`.

Aliases for the iMessage bridge: **cube**, **block** (not `square` — that stays the flat 2-D glyph).
